# Docsheaf

Docsheaf is a hosted documentation platform: write in a block editor, review every change like a pull request, and publish LLM-ready docs sites.

- **Block editor**: hints, tabs, steppers, code, tables, math, diagrams and embeds, with Markdown shortcuts.
- **Change requests**: edit on a branch, review the diff and merge when it's approved. Concurrent edits merge block by block.
- **Docs sites and knowledge bases**: fast, branded and searchable, on a docsheaf.io subdomain or your own domain, public or private.
- **Ready for AI tools**: every site serves `llms.txt`, `llms-full.txt` and a Markdown version of every page, and can offer an MCP server and an AI assistant that answers from your docs.
- **Git Sync**: two-way sync between a space and a folder of Markdown in a GitHub or GitLab repository.
- **No lock-in**: GitBook-style Markdown imports as it is, and everything exports back to Markdown.
